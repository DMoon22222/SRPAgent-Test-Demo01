## 复现命令

在取得本轮工具的 B `python_service` 目录执行：

```powershell
# 从当前仓库直接使用新配置；真实目标仅为固定合成任务。
& '.\.venv-local-v2\Scripts\python.exe' -B scripts/verify_p2_local.py --docker

# 配置也可位于共同仓库/O 的目录，实际已按此方式复核。
& '.\.venv-local-v2\Scripts\python.exe' -B scripts/verify_p2_local.py --docker --config ../../reliable_codegen_framework/config.b-local.p2.example.json --manifest ../../reliable_codegen_framework/modules/b/p2_handoff_manifest_v0.3.1.json
```

配置保持 local、adaptive_rag、两次修复上限和 15 秒传输时限。每次运行仅覆盖 B 私有状态与 O 输出目录到唯一运行目录；检查实际镜像，版本不符明确失败。其他机器若无同一镜像，需取得该镜像或另行登记并验证新环境，不能用不同构建冒充相同证据。
